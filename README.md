# Crisis Preparedness Library

Landing page for our interactive crisis-preparedness stories (Interactive Digital Narratives).

| Item | Value |
|---|---|
| Live URL | `interactivedigitalnarrative.github.io/` |
| Games | Own repos, served at `/<storyId>/` (e.g. `/storm-alert/`) |
| Stack | React + Vite |
| Deploy | Push to `main` → GitHub Pages |
| Data contract | `docs/platform/data-contract.md` in the `storm-alert` repo |

## Run locally
```
npm install
npm run dev
```
